# 学習履歴削除機能の追加完了報告

学習履歴画面において、個別の履歴選択削除および全履歴の一括削除機能を実装しました。

## 変更内容

### 1. データレイヤーの拡張
- `StudyTaskDao` および `StudyTaskRepository` に、複数のタスクを一括削除するための `deleteTasks` メソッドを追加しました。

### 2. ViewModel レイヤーの強化
- `TaskListViewModel` に履歴の選択状態（`selectedHistoryIds`）を管理するロジックを追加しました。
- 選択された履歴のみを削除する `deleteSelectedHistory()` および、すべての履歴を削除する `deleteAllHistory()` を実装しました。

### 3. UI の更新 (HistoryScreen)
- **チェックボックスの追加**: 各履歴アイテムの左側にチェックボックスを配置し、タップで選択状態を切り替えられるようにしました。
- **選択削除ボタン**: 1つ以上の履歴が選択されている場合に、画面右上のゴミ箱アイコンから削除が可能になります。
- **全履歴削除ボタン**: 画面右上の赤いゴミ箱アイコンから、すべての完了済み記録を一括で削除できます。
- **確認ダイアログ**: 誤操作防止のため、削除実行前には必ず確認ダイアログを表示するようにしました。

## 使用方法
1. 学習履歴画面を開きます。
2. 削除したい項目のチェックボックスをオンにします。
3. 画面右上の「削除」アイコン（左側）をタップして選択削除を実行します。
4. 全ての履歴を消したい場合は、赤い「全削除」アイコン（右側）をタップします。

> [!CAUTION]
> 履歴の削除は取り消すことができません。削除前に表示される確認ダイアログの内容をよくご確認ください。
