## 「集中学習タイマー」アプリ

これまで学習した、画面レイアウト、状態管理、タイマー、リスト表示、データベース、画面遷移などを組み合わせたアプリです。

### 1. アプリの概要

勉強する内容を登録し、選択した課題について集中時間を計測するアプリを作成してください。

利用者は、次のような流れでアプリを使用します。

1. 学習する内容を登録する
1. 登録した学習項目を選択する
1. 集中時間を設定する
1. カウントダウンを開始する
1. 終了した学習項目を完了にする

### 2. 想定開発時間

#### 10～15時間

これまでの学習内容を参考にして作成

#### 1～2時間

chatgpt等、生成AIを活用

### 3. 画面構成

アプリは、次の2画面で構成します。

#### 画面1：学習項目一覧画面

登録した学習項目を一覧表示します。

表示例：

```
集中学習タイマー

学習内容を入力
[　　　　　　　　　] [追加]

□ Kotlinの復習
□ Jetpack Composeの復習
■ Roomの課題

完了：1件 / 全体：3件
```

#### 画面2：タイマー画面

一覧画面で選択した学習項目について、カウントダウンを行います。

表示例：

```
Kotlinの復習

残り時間

24:35

[開始] [一時停止]
[リセット]

学習完了
```

### 4. 必須機能

#### 4.1 学習項目の追加

一覧画面に次の部品を配置します。

- `TextField`
- 追加ボタン
- 学習項目の一覧

追加ボタンを押すと、入力した内容を一覧に追加します。

##### 入力条件

- 空文字は登録できない
- 空文字で追加しようとした場合は、エラーメッセージを表示する
- 正常に追加した後は入力欄を空にする

#### 4.2 学習項目の一覧表示

登録された学習項目を、`LazyColumn`を使用して表示します。  
各項目には、次の内容を表示してください。

- 完了状態を表すチェックボックス
- 学習内容
- タイマー画面へ移動するボタン
- 削除ボタン

表示例：

```
□ Kotlinの復習       [開始] [削除]
□ Composeの復習      [開始] [削除]
■ Roomの課題         [開始] [削除]
```

#### 4.3 完了状態の切り替え

チェックボックスを押すと、完了状態を切り替えます。

##### 未完了の場合

- 通常の文字で表示する

##### 完了の場合

- 文字に取り消し線を付ける
- 文字色を薄くする
- 完了件数に加算する

#### 4.4 学習項目の削除

削除ボタンを押すと、対象の学習項目を削除します。  
可能であれば、削除前に確認ダイアログを表示してください。

```
「Kotlinの復習」を削除しますか？

[キャンセル] [削除]
```

確認ダイアログは`AlertDialog`を使用します。

#### 4.5 件数表示

画面下部に、完了件数と全体件数を表示します。

```
完了：2件 / 全体：5件
```

全件完了した場合は、次のメッセージを表示します。

```
すべての学習が完了しました！
```

ただし、登録件数が0件の場合には、このメッセージを表示しないようにしてください。

#### 4.6 タイマー画面への移動

学習項目の「開始」ボタンを押すと、その項目のタイマー画面を表示します。  
タイマー画面には、選択した学習内容を表示します。

```
Kotlinの復習
```

画面遷移には、Navigation Composeを使用してください。

画面構成の例：

```
一覧画面
  ↓
タイマー画面
  ↓
一覧画面
```

#### 4.7 集中時間の選択

タイマー画面では、開始前に集中時間を選択できるようにします。  
選択肢は次の3種類とします。

- 1分
- 5分
- 25分

`RadioButton`、`FilterChip`、またはボタンを使用して実装してください。  
初期値は **25分** とします。

#### 4.8 カウントダウン

選択した時間から、1秒ずつカウントダウンします。  
表示形式は次のとおりです。

```
25:00
24:59
24:58
```

表示は必ず「分:秒」とし、秒が1桁の場合は先頭に0を付けます。  
例：

```
5:07
```

#### 4.9 タイマー操作

タイマーには、次の操作を実装します。

##### 開始

カウントダウンを開始します。

##### 一時停止

カウントダウンを一時停止します。

##### 再開

停止している位置からカウントダウンを再開します。

##### リセット

選択した時間の初期値に戻します。

#### 4.10 タイマー終了

残り時間が0になったら、次の処理を行います。

- カウントダウンを停止する
- 終了メッセージを表示する
- 「学習完了」ボタンを表示する

表示例：

```
集中時間が終了しました！

[学習完了]
```

「学習完了」ボタンを押すと、次の処理を行います。

1. 対象の学習項目を完了状態にする
1. 一覧画面へ戻る

#### 4.11 データの保存

学習項目はRoomデータベースに保存します。  
アプリを終了して再起動しても、登録した内容が残るようにしてください。  
保存するデータの例：

```kotlin
@Entity
data class StudyTask(
    @PrimaryKey(autoGenerate = true)
    val id: Int = 0,
    val title: String,
    val isCompleted: Boolean = false
)
```

DAOには、最低限、次の処理を用意します。

```kotlin
@Insert
suspend fun insert(task: StudyTask)

@Update
suspend fun update(task: StudyTask)

@Delete
suspend fun delete(task: StudyTask)

@Query("SELECT * FROM StudyTask ORDER BY id DESC")
fun getAll(): Flow<List<StudyTask>>
```

テーブル名や関数名は変更して構いません。

### 5. 実装条件

次の技術を使用してください。

- Kotlin
- Jetpack Compose
- Material 3
- ViewModel
- Navigation Compose
- Room
- Coroutineまたは`LaunchedEffect`
- `LazyColumn`

また、次の点を守ってください。

- Composable内で直接ViewModelを生成しない
- 画面の状態はViewModelで管理する
- 表示用Composableとデータ処理を可能な範囲で分離する
- タイマーが0未満にならないようにする
- 削除後に、削除済みデータを取得しないようにする
- アプリが異常終了しないようにする

### 6. データ構造の例

```kotlin
data class TimerUiState(
    val taskId: Int = 0,
    val taskTitle: String = "",
    val selectedMinutes: Int = 25,
    val remainingSeconds: Int = 25 * 60,
    val isRunning: Boolean = false,
    val isFinished: Boolean = false
)
```

この形をそのまま使用する必要はありません。

### 7. 画面遷移の例

```kotlin
sealed class Screen(val route: String) {
    data object TaskList : Screen("task_list")

    data object Timer : Screen("timer/{taskId}") {
        fun createRoute(taskId: Int): String {
            return "timer/$taskId"
        }
    }
}
```

タイマー画面へ移動するときは、学習項目のIDを渡します。

```kotlin
navController.navigate(Screen.Timer.createRoute(task.id))
```

### 8. 発展課題

時間に余裕がある場合のみ実装します。必須ではありません。

#### 発展1：完了項目の一括削除

「完了済みを削除」ボタンを追加します。  
完了状態になっている項目をまとめて削除します。

#### 発展2：表示の絞り込み

次の3種類で一覧を切り替えます。

- すべて
- 未完了
- 完了済み

`TabRow`または`FilterChip`を使用します。

#### 発展3：タイマー終了時のアニメーション

タイマー終了時に、文字やアイコンをアニメーション表示します  
使用例：

- `AnimatedVisibility`
- `animateColorAsState`
- `animateFloatAsState`

#### 発展4：効果音

タイマー終了時に効果音を鳴らします。  
Pianoアプリなどで学習した音声再生を応用します。

#### 発展5：学習記録

学習を完了した日時を保存し、履歴画面に表示します。

```
学習履歴

Kotlinの復習
2026/07/29 21:30

Composeの復習
2026/07/28 18:15
```
